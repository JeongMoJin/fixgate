# LLM 단독 vs FixGate (2026-10-28, 두 모델)

같은 질문을 두 방식으로 물었다: **"이 서비스가 운영에 쓰는 패키지 버전 중 취약한 것은? 해당 권고 ID는? 취약점을 모두 없애는 가장 작은 업그레이드 버전은?"**

- **LLM 단독:** 도구 없이 패키지 이름과 버전만 주고 물었다. 모르면 unknown이라고 답하게 했다. 두 모델로 돌렸다.
  - Claude Sonnet(Claude Code `sonnet` 별칭): FixGate의 지시문(주어진 사실만 쓰라) 그대로.
  - OpenAI gpt-6.1-terra(추론 강도 low): 같은 지시문이면 440개 모두 "모른다"로 답해 비교가 되지 않았다. 그래서 중립 지시문("아는 지식으로 답하라")으로 다시 돌렸다.
- **FixGate:** 같은 패키지를 OSV에서 조회하고, 업그레이드 버전은 npm registry 목록에서 골라 후보마다 OSV로 확인한다.
- **정답:** 실행 시점(2026-10-28)의 OSV. 권고 ID는 OSV ID나 그 별칭(CVE 등)이 해당 패키지·버전에 걸려 있을 때만 맞은 것으로 쳤다.
- **대상:** `examples/shop-api`와 [benchmark.md](benchmark.md)의 공개 프로젝트 9개. 각 서비스의 운영용 직접 의존성 최대 60개, 모두 440개.

| 질문 | Claude Sonnet | gpt-6.1-terra (중립 지시) | FixGate |
|---|---|---|---|
| 취약한 패키지를 찾아냄 | 17 / 28 (60.7%) | 14 / 28 (50.0%) | 28 / 28 |
| '취약하다'고 한 것 중 실제로 취약 | 17 / 19 (89.5%) | 14 / 16 (87.5%) | OSV 그대로 |
| 말한 권고 ID가 실제로 그 버전에 해당 | 31 / 58 (53.4%) | 32 / 42 (76.2%) | ID를 만들지 않음 |
| 실제 권고 중 이름을 댄 것 | 30 / 128 (23.4%) | 31 / 128 (24.2%) | 128 / 128 |
| └ 2025년 이전에 공개된 권고 | 20 / 29 (69.0%) | 19 / 29 (65.5%) | 29 / 29 |
| └ 2025년 이후에 공개된 권고 | 10 / 99 (10.1%) | 12 / 99 (12.1%) | 99 / 99 |
| 제안한 버전이 npm에 실제로 있음 | 16 / 16 (100%) | 4 / 4 (100%) | registry 목록에서 고름 |
| 제안한 버전에 알려진 취약점이 없음 | 7 / 16 (43.8%) | 2 / 4 (50.0%) | 후보마다 OSV 확인 |
| 모른다고 답함 | 222 / 440 | 403 / 440 | — |

두 모델의 모양이 같다: 2025년 이전 권고는 3분의 2쯤 짚지만, 그 뒤 권고는 10% 남짓이다.

## 읽는 법

- 모델은 오래된 권고는 꽤 안다: 2025년 이전에 공개된 권고는 두 모델 모두 3분의 2쯤 짚었다. 하지만 2025년 이후 공개된 권고는 99건 중 10~12건만 짚었다. 모델 지식은 학습 시점에 멈추고, 2025년 한 해에만 CVE가 48,185건 나왔다.
- 권고 ID의 절반가량이 그 버전에 해당하지 않았고, 제안한 업그레이드 버전 16개 중 9개에는 그 뒤 공개된 취약점이 남아 있었다.
- 최근 버전에는 절반이 "모른다"였다. 정직한 답이지만 우선순위를 정할 수는 없다.
- 이 비교는 FixGate가 '더 똑똑하다'는 주장이 아니다. FixGate의 100%는 정답(OSV)을 그대로 가져오기 때문이고, 표가 보여 주는 것은 사실 판단을 모델 기억에 맡기면 안 되는 이유다.

FixGate가 LLM을 사실 판단(취약 여부, 버전, 점수)에 쓰지 않고, 관문이 실패했을 때 주어진 사실만으로 원인을 설명하는 데에만 쓰는 이유다.

## 다시 돌리기

```bash
FIXGATE_LLM=claude-code BASELINE_MODE=strict node scripts/baseline.ts examples/shop-api <benchmark 폴더들>
FIXGATE_LLM=openai OPENAI_API_KEY=... node scripts/baseline.ts examples/shop-api <benchmark 폴더들>
```

LLM 답은 `.fixgate-cache/llm/`에 남아 같은 질문은 다시 호출하지 않는다. 모델마다 17회씩 호출했고, gpt-6.1-terra 두 번(지시문 두 가지)에 든 비용은 $0.17이다.
